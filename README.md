# 스쿼시 분석 · 자세 교정

## 처음 쓰는 분 (코드를 몰라도 됩니다)

1. 컴퓨터에 [Python 3](https://www.python.org/downloads/)을 설치합니다 (맥은 대부분 이미 있습니다).
2. 이 폴더의 **`start.command`**(맥) 또는 **`start.bat`**(윈도우)을 **더블클릭**합니다.
   - 처음 한 번은 필요한 프로그램을 내려받느라 10분쯤 걸립니다. 검은 창을 닫지 마세요.
   - 맥에서 "확인되지 않은 개발자" 경고가 뜨면: 파일을 우클릭 → 열기 → 열기.
3. 잠시 뒤 브라우저에 분석 화면이 열립니다. 순서대로 따라 하세요.
   1. 영상 올리기
   2. 코트 바닥 선 위의 점 4~5개 클릭 (이동 거리/코트맵용, 건너뛰어도 됩니다)
   3. 선수 이름과 분석 구간 입력 → **분석 시작**
4. 결과 영상은 화면에서 바로 재생되고, 이 폴더의 `outputs`에도 저장됩니다.

결과 영상에는 선수 이름표, 이동 속도, 타격 횟수와 타격 순간 배너, 이동 거리, 코트맵이 중계 화면처럼 표시되고
원본 소리도 그대로 들어갑니다.

알아둘 점
- **카메라가 고정(삼각대)된 영상**에서 코트 보정이 정확합니다. 손에 들고 찍어 흔들리면 이동 거리/코트맵이 틀어집니다.
- 그래픽카드(GPU)가 없으면 느립니다. 1분 영상에 7~10분쯤 걸리니 처음엔 **30초 정도 구간**으로 시험해 보세요.
- 타격 횟수는 손목이 빠르게 움직인 순간을 센 **추정값**입니다(공을 보지 않아서 연습 스윙이 섞일 수 있어요).
- 득점자는 "마지막에 친 사람"으로 추정한 값이라 앱에서 랠리별로 바로잡아야 합니다.
- 공 인식은 GPU에서 학습한 모델(`models/ball.pt`)이 있어야 합니다. 자세한 방법은 `사용 설명서.md`를 보세요.
- 샷 종류(포핸드/백핸드 등)는 아직 없습니다.

개발자용: `python app.py` (웹 앱), `python track_overlay.py --help` (CLI), `label_ball.py`/`train_ball.py`/`pseudo_label.py` (공 탐지 학습), `ball_track.py`/`rally.py` (궤적 후처리, 랠리/점수). 자세한 설명은 `사용 설명서.md`.

## 자세 교정 (관절 각도 비교)

YOLO pose로 관절 각도를 뽑아, 여러 선수 영상으로 만든 레퍼런스와 내 자세를 비교해
어떤 관절이 얼마나 벗어났는지 알려주는 도구.

RGB 카메라라 깊이(depth) 정보가 없어서 정확한 3D 몸 방향은 알 수 없다. 대신 어깨
너비/몸통 길이 비율로 "카메라를 얼마나 정면으로 보고 있는지"를 근사하고, 비교할 때
나와 비슷한 방향인 레퍼런스 샘플만 걸러서 평균±표준편차를 낸다. 완전히 다른 각도에서
찍힌 레퍼런스와 비교되는 걸 어느 정도 막기 위함.

## 1. 의존성 설치

```bash
pip3 install -r requirements.txt
```

(ultralytics가 torch까지 같이 설치해서 시간이 좀 걸립니다.)

## 2. 선수 영상 준비

영상 파일(`.mp4` 등)을 이 폴더에 넣고, 재생하면서 임팩트(스윙이 공에 닿는) 순간의
**프레임 번호**를 확인합니다. (30fps 영상이면 1초 = 30프레임)

## 3. 샘플 목록 작성 (`samples.txt`)

`영상파일,프레임번호,샷종류`를 한 줄에 하나씩 (샷종류는 생략 가능, 기본값 "일반"):

```
player1.mp4,42,포핸드드라이브
player1.mp4,110,백핸드발리
player2.mp4,58,포핸드드라이브
# 주석은 #으로 시작
```

포핸드/백핸드/발리/보스트처럼 상황이 다르면 이상적인 자세도 많이 달라지기 때문에,
비교할 때(5번) 같은 샷종류끼리만 묶어서 봅니다. 샷종류·관절당 5~10개 샘플은 있는
게 좋습니다. 샘플이 너무 적으면(n=1~2) 표준편차가 0에 가까워서 살짝만 벗어나도
"교정 필요"로 뜰 수 있습니다.

## 4. 레퍼런스 생성

```bash
python3 build_reference.py --list samples.txt --out reference.json
```

각 샘플의 관절 각도 + 몸 방향(orientation)이 `reference.json`에 원본 리스트로
저장됩니다. 평균/표준편차는 여기서 내지 않고, 비교 시점(5번)에 방향이 비슷한
샘플만 골라서 그때 계산합니다.

## 5. 내 자세와 비교

```bash
python3 pose_compare.py --reference reference.json --user 내영상.mp4 --user-frame 30 --shot-type 포핸드드라이브
```

`--user-frame`은 내 영상에서 비교하고 싶은 순간(보통 임팩트)의 프레임 번호입니다.
`--shot-type`을 지정하면 같은 샷종류인 레퍼런스만 먼저 걸러내고, 그중에서 내 방향과
비슷한 샘플만 다시 골라(둘 다 부족하면 그 단계에서 전체로 폴백) 관절별 각도를 비교,
기준에서 15도(또는 표준편차\*2) 이상 벗어난 관절에 대한 교정 피드백을 출력합니다.

## 옵션

- `--shot-type`: 포핸드드라이브 등 samples.txt에 적은 샷 이름. 생략하면 전체 샷 통틀어 비교
- `--model`: 사용할 YOLO pose 모델 (기본값 `yolo11n-pose.pt`, 처음 실행 시 자동 다운로드)
